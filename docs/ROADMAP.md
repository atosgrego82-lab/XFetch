# XFetch roadmap

XFetch is an experimental open-source Xbox 360 RGH homebrew project.

## Target experience
Search approved homebrew/ROM catalogs, inspect metadata, download a selected file, verify its checksum, and install it to a user-selected emulator ROM folder.

## Milestones
1. Verify a freely distributable Xbox 360 homebrew toolchain and .xex packaging flow.
2. Build and run a minimal Hello World .xex on actual Xbox 360 RGH hardware.
3. Implement controller-driven UI, networking, and filesystem access.
4. Implement repository catalog format and search.
5. Add safe downloads with checksum, free-space check, cancellation and path restrictions.
6. Add emulator-specific installation profiles.

No copyrighted commercial ROMs are included or hosted.
